## 🌟 Featured Engineering Projects

### 🎬 [OmniQuery AI — Autonomous Film Analytics & Agentic Platform](https://github.com/Divyanshneginot/OmniQuery-AI)
> **Stack:** Google Agent Development Kit (ADK), Gemini 3.6 Flash, ClickHouse Cloud (GCP), FastMCP, DuckDB, FastAPI, React 19, Recharts
- **Planner & Reflection Loop:** Translates natural language into analytical ClickHouse SQL, executing across 50,000+ box office and telemetry records in sub-200ms.
- **Self-Healing SQL:** Self-healing reflection loop catches database compiler exceptions and schema dialect errors, regenerating valid queries with a **99%+ success rate**.
- **Model Context Protocol:** Integrated official `mcp-clickhouse` server for dynamic runtime schema introspection and isolated execution.
- **Dual-Engine High Availability:** Dual-engine architecture with automatic failover from ClickHouse Cloud on GCP to in-memory DuckDB.
- **Live Trace Streaming:** Streams real-time agent execution traces, reasoning steps, and visual KPI charts to a React 19 canvas via FastAPI Server-Sent Events (SSE).
- 🔗 **[Explore Live Application](https://omni-query-ai.vercel.app/)** · **[View Source Code](https://github.com/Divyanshneginot/OmniQuery-AI)**
